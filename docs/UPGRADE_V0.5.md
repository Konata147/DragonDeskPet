# V0.5 升级与回退指引

适用于自包含 Windows x64 ZIP。新版不会自动迁移或覆盖旧版数据。

1. 从旧版桌宠的系统托盘选择「退出」，确认旧进程结束；只关闭聊天气泡不算退出。
2. 将旧程序旁完整的 `data/` 文件夹复制到自己选择的备份目录。它可能含设置、加密 API Key、课表和提醒，请保存在本机，不上传到公开仓库。
3. 将 V0.5 ZIP 完整解压到新的目录，保留旧程序目录。不要在 ZIP 内运行，也不要只复制 EXE。
4. 若需沿用旧数据，将备份的整个 `data/` 复制到新目录的 `DragonDeskPet.exe` 旁。若新目录已经有 `data/`，先分别备份并选择其中一份，不混合 JSON 文件。
5. 启动新版，检查桌宠位置、缩放、设置及自己的课表。API Key 使用 Windows 当前用户范围加密；跨用户或跨电脑时可能需要重新配置。

单实例保护会使“旧版未退出时启动新版”仅唤醒旧版。升级不需要删除旧包或旧数据。

回退时先退出新版，并另外保存新版 `data/`；再启动保留的旧程序和升级前备份。旧版可能不理解新版写入的设置或效率数据字段，不要让旧版直接覆盖唯一一份新版数据。V0.4 的课程数据与操作边界详见 [原升级指引](UPGRADE_V0.4.md)。
