# DragonDeskPet V0.2.0

V0.2 将龙娘桌宠从纯文字聊天扩展为“桌面内容问 AI”，同时保持桌宠界面轻量、非模态和用户确认后才发送的隐私边界。

## 新功能

- 区域截图问 AI：支持单显示器选区、多显示器坐标与 Per-Monitor V2 DPI。
- 剪贴板问 AI：仅在用户点击时读取一次文字、Bitmap 或复制的单张图片文件。
- 图片拖入：支持单张 PNG、JPG、BMP、GIF 和 TIFF，其他文件会明确拒绝。
- 图片预览：显示来源、尺寸和编码大小，发送前可编辑问题或移除图片。
- 视觉模型请求：OpenAI-compatible `text + image_url` 格式，已通过 DeepSeek `deepseek-flash` 实机验证。

## 隐私与限制

- 截图、剪贴板图片和拖入图片只保存在内存中，不写入缓存、日志或临时文件。
- 内容不会自动上传；只有点击“发送”后才交给当前配置的模型服务。
- 图片最长边限制为 2560 像素，PNG 编码结果超过 8 MiB 时拒绝发送。
- V0.2 不包含后台剪贴板监控、非图片文档读取、OCR、全局快捷键、提醒或截图历史。

## 验证

- Debug 与 Release 均以 0 错误、0 警告构建。
- 21 项自动冒烟测试通过。
- 区域截图、剪贴板文字/图片、复制图片文件、图片拖入、失败重试和不支持文件提示均通过实机检查。
