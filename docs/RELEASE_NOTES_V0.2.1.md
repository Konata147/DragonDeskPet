# DragonDeskPet V0.2.1

V0.2.1 是 V0.2 的桌面体验补丁，保留原有截图、剪贴板、图片拖入和 AI Provider 行为。

## 界面与布局

- 左键快捷栏改为紧凑的淡紫色圆形图标栏，常用入口保留聊天、截图和粘贴。
- 置顶与设置收进“更多”菜单，置顶状态以 `✓` 或 `○` 明确显示。
- 快捷栏随桌宠缩放并保持在角色左侧，点击其他窗口时自动收起。
- 扩展透明安全区域并重构定位逻辑，修复 200% 缩放和悬停动画时角色、气泡、圆角与阴影被裁切的问题。
- 旧版本保存的桌面位置继续兼容，不会因安全区域变化而突然跳位。

## 全屏程序兼容

- 新增“全屏程序运行时自动隐藏”设置，默认开启。
- 当前台窗口完整覆盖所在显示器时自动隐藏桌宠，离开全屏后静默恢复且不抢焦点。
- 普通最大化窗口不会触发；支持负坐标副显示器。
- 仅检查前台窗口边界，不读取内容、不注入游戏进程。
- 手动隐藏与自动隐藏分离：用户手动隐藏后不会被全屏状态变化自动唤醒。

## 验证

- Debug 与 Release 均以 0 错误、0 警告构建。
- 22 项自动冒烟测试通过。
- 200% 缩放布局、置顶状态与全屏自动隐藏/恢复均通过实机检查。
