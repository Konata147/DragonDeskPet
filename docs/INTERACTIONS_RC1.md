# DragonDeskPet 互动候选版说明（本地，未正式发布）

候选版本：`0.4.0-interactions.18-rc1`，基于已试用的 `.18` 功能代码。此候选版只重新构建并整理已完成的互动，没有改角色、小 AI 素材、动作节奏或鼠标参数，也没有更动 V0.4 课程功能。

## 本轮互动内容

- 角色的招呼、摸头、投喂、贴贴、蹦跳、舞蹈、伸展、张望、落地、叫醒、庆祝及睡眠使用各自的有限动作；待机以低频眨眼等局部动作保持安静。
- 保留短点快捷栏、双击聊天、拖动桌宠、长按贴贴、轻扫摸头与点击小 AI。靠近角色可使用点心、音符和星星道具；点心可选五种，舞蹈可选三支。
- 小 AI 对点心和舞蹈有对应回应；安静待机一段时间后可短暂邀请选择点心或舞蹈，点击邀请才展开选择栏。
- 「减少动态效果」继续使用代表性静态姿势；隐藏、睡眠及其他操作会中断正在播放的互动。

## 候选检查

- 两组新互动专项检查通过，覆盖手势互斥、动作中断与旧回调、投喂取消、静态模式、邀请冷却及 60%／100%／200% 的离屏布局；Release 构建为零警告、零错误。
- 新增长待机模拟：入睡前只出现一次邀请，睡眠期间不再出现，唤醒后经过等待才恢复邀请。实际桌面的一次邀请出现、点击选择栏和忽略收起已获用户反馈；长时段桌面试用与系统 DPI 矩阵未据此宣称实测通过。
- 141 张角色 PNG 与 `.18` 逐一 SHA-256 一致；候选目录和 ZIP 均无 `data/`、参考图或个人课表文件。
