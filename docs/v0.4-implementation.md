## First manual acceptance steps

### Bounded HTTPS recovery (latest staged update)

User verified the teacher-comparison fix: actual school preview is 0 updates,
13 duplicates and 1 invalid note. Reopening school import requires login again.
User authorized improving the extra manual retry after login.

Added a narrow recovery policy: a canceled server redirect belonging to a known
allowed navigation may return once to the fixed HTTPS entry only when its target
is HTTP on the exact school host/default port and contains no userinfo. The HTTP
request remains canceled; its path/query/body are never replayed or forwarded.
Other origins, nonstandard ports, unrelated navigation ids and non-redirects do
not trigger recovery. A new navigation starts after the cancellation callback,
unless the window closed or another navigation superseded it. The one-shot
budget is reset only by explicit manual Retry, preventing automatic loops.
