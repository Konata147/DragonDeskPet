# V0.5 互动验收与发布检查

记录于 2026-10-02。用户已明确同意将已整理的互动候选版正式推送并发布。V0.4 的人工验收结论保留，不重复要求用户走旧流程。

## 已核对

- `.9` 的短点、双击、拖动、长按贴贴和小 AI 点击，用户反馈均正常、手感顺畅；`.14` 的悬停收尾、`.17` 的点心与舞蹈选择，以及 `.18` 的邀请出现／点击／自行收起，也分别取得用户实机反馈。这些反馈各有明确范围，不等于全部组合都经实机验证。
- V0.5 的完整自动冒烟测试通过；两组互动专项检查覆盖手势互斥、旧回调打断、投喂取消、五种点心与三支舞、小 AI 表情、素材边界和 60%／100%／200% 的 WPF 离屏布局。
- 15 分钟虚拟时间检查覆盖邀请出现、自动入睡时保持安静、唤醒后重新等待。它不是 15 分钟真实桌面操作记录。
- Debug 和 Release 均以警告视为错误构建成功，零警告、零错误。本机使用 .NET 9 预览 SDK 编译 net8.0-windows；正式提交需另看 GitHub Actions 上稳定 .NET 8 的结果。
- 正式自包含目录 `dist/DragonDeskPet-v0.5.0-win-x64/` 共 651 个文件，含 141 张角色 PNG 和本地 OCR 模型。141 张 PNG 与 `.18-rc1` 候选逐一哈希相同。目录和 ZIP 无运行 `data/`、参考图、课表 XLS/XLSX、数据库、日志或调试符号；ZIP 的 651 个文件均可完整读取。
- ZIP：`DragonDeskPet-v0.5.0-win-x64.zip`，161,899,174 字节；SHA-256：`A40330950C4849FB485FDADE38FF26596B902827E56B16C5CA9830480D297ABA`。配套 `.sha256.txt` 与实测哈希一致。
