# DragonDeskPet V0.5.0

V0.5 让桌宠本身更有生命力：互动动作各有自己的姿势和节奏，点心、舞蹈与小 AI 可以直接从桌面触发。角色外观与大小沿用原设，V0.4 的课表和校园功能继续保留。

## 角色与小 AI

- 招呼、摸头、投喂、贴贴、蹦跳、舞蹈、伸展、张望、落地、叫醒和庆祝使用各自的一次性动作；入睡时保持独立睡姿。普通互动不再通用地整身左右摇晃；跳跃只作纵向位移，其他动作结束后站稳。
- 待机以低频眨眼等局部变化为主。小 AI 使用独立透明表情，对五种点心、三支舞蹈及点击分别回应，不带动角色整身摆动。
- 动作被拖动、思考、睡眠或隐藏打断时，旧动作与旧回调不能覆盖新状态；减少动态效果时使用代表性静态姿势。素材缺失时回退静态状态图。

## 直接互动

- 短点仍打开快捷栏，双击仍打开聊天，拖动仍移动桌宠；左键长按约 550 毫秒可贴贴，轻扫头顶可摸摸头。点小 AI 得到它自己的短回应，从它的位置拖动仍能移动桌宠。
- 靠近桌宠出现点心、音符和星星道具。点心可选饼干、草莓、蛋糕、糖果、棉花糖，拖到嘴边释放后投喂；Esc 或目标外释放取消。音符可选轻快踏步、国风轻舞、翼尾合拍，星星触发蹦跳。右键菜单仍可打开互动入口。
- 小 AI 在连续安静待机约两分钟后短暂邀请选择点心或舞蹈；邀请约八秒后自行收起，至少四分钟冷却。点击才打开选择栏，不自动投喂或跳舞；入睡、专注、隐藏等状态会抑制邀请。连续无人操作约五分钟会自动入睡，因此不保证同一段无人操作中出现第二次邀请。
- 国风轻舞借鉴国风感觉，没有内置或播放《琵琶曲》，也不复刻特定编舞。没有新增音频。

## 下载与升级

下载 `DragonDeskPet-v0.5.0-win-x64.zip` 并完整解压。包内包含 .NET 运行环境和本地 OCR 模型；不能只复制 EXE。可用同页 `.sha256.txt` 校验完整性。

旧版仍在运行时启动新版，只会唤醒单实例旧版。请从托盘退出旧版，先备份旧目录的完整 `data/`，再在新目录启动；需要沿用设置和课表时，按[升级与回退指引](UPGRADE_V0.5.md)复制备份。发布包不含用户数据，也不会自动替换旧目录。

## 验证范围与限制

- V0.5 的两组新互动专项检查、15 分钟虚拟待机／入睡／唤醒检查，以及 60%／100%／200% 的 WPF 离屏布局检查通过。用户此前对基础手势、选择栏和小 AI 邀请主流程分别给出真实桌面反馈；这不等于全部组合都经过实机验收。
- 本机 Release 构建通过。正式提交的稳定 .NET 8 CI 结果以 GitHub Actions 为准，不能用 V0.4 的 CI 结果代替。
- 透明桌宠窗口未能被当前桌面自动化工具识别；长时间真实桌面待机及 Windows 系统 DPI 完整矩阵未作为已实测项。V0.4 已记录的无 WebView2 环境下载、异常浏览器退出清理、部分课程提醒边界等限制仍在，见 [V0.4 验收记录](v0.4-acceptance.md)。
- 本版没有安装程序和数字签名；角色及图标素材遵循单独的 [素材许可](../ASSET_LICENSE.md)，不属于代码 MIT 许可。
