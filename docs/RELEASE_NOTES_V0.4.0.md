# DragonDeskPet V0.4.0

V0.4 聚焦课表增强与校园体验：导入方式更丰富，支持冬夏作息、整周查看和临时调课，
仍然保留紧凑的桌宠界面，不扩展为大型效率软件。

本地课表识图和效率功能无需 API Key。原有聊天、截图问 AI 等功能继续保留。

## 课表导入

- 新增 `.xls` / `.xlsx`，无需安装 Office；保留 ICS 和 UTF-8 CSV。
  首批支持湖南工程学院周课表和项目标准字段的行式表格，多工作表可选择。
  不承诺任意学校 Excel 布局，不执行宏或外部链接。
- 新增 PNG、JPG/JPEG 课表截图的本地中文识别。随包附带模型，不需要 API Key，
  不把课表图片发送给 AI。需包含星期表头、节次与尽量完整的课程文字；
  省略号、缺失字段和不确定结果必须核对补齐，不能从截断文字恢复不存在的信息。
- 新增湖南工程学院教务导入：用户自行登录、输入验证码、打开个人课表后主动读取。
  当前学校页面已实测；不自动登录、不绕过验证码或证书检查。
  同校服务器降级到 HTTP 的跳转会被取消，并限次返回固定 HTTPS 入口。
- 导入先预览，可编辑或排除记录；显示新增、更新、重复、无效及冲突。
  默认合并，替换当前学期需明确确认。预览或取消不改已有课表。
- 支持跨重启撤销上次成功导入。撤销会回退其后的课程相关编辑，确认前需阅读差异提示；
  不回滚清单、普通提醒或番茄钟，不重新补发已处理的旧课程提醒。

## 日常课表体验

- 本周课表支持前后翻周、回到本周、实际日期和教学周；无课位置留空。
  同节次课程对齐，冬夏实际钟点独立显示，冲突课程不相互覆盖。
- 今日页显示正在进行和下一节课；当天无课或课程已结束时给出明确状态。
- 可按起止节次与实际日期计算冬夏钟点，支持不连续周次、单双周。
  旧固定钟点课程不自动改成节次课程；校历节假日不会自动视为停课。
- 支持仅调整某次课程的日期、时间和地点，以及保留原课的单次补课。
  今日、周课表与提醒使用统一的实际课程安排；支持撤销单次调整。
- 导入、编辑和调课等操作检查实际日期与时段冲突，首尾相接不算冲突。
  用户可明确选择保留冲突，不自动删除或擅改课程。

## 修复与优化

- 修复专注页汉字裁切、长课程文字与卡片字段排版，沿用紫色主题滚动条。
- 导入显示阶段、耗时及取消入口；文件被 WPS/Excel 占用时给出可见的处理提示。
- 修复多位教师顺序或分隔符不同导致的假更新；真正增减教师仍提示更新。
- 教务加载失败显示安全的错误码，不再将所有取消或拦截都误报为断网。

## 运行、升级与隐私

- 下载 `DragonDeskPet-v0.4.0-win-x64.zip`，自带 .NET 运行环境与本地识图模型。
  可使用同页 `.sha256.txt` 附件核对压缩包完整性。
- 需完整解压，不能只复制 EXE；本地 OCR 依赖随包模型及原生库。
- 教务窗口依赖 WebView2，优先使用已安装运行时；缺失时由用户确认下载便携版本。
  不自动执行系统安装器，不把运行时写到 C 盘。
- 升级先退出旧版并备份 `data`，推荐独立新目录，详见[升级与回退指引](https://github.com/Konata147/DragonDeskPet/blob/v0.4.0/docs/UPGRADE_V0.4.md)。
- 课表、识别图片和效率数据不交给 AI；教务会话使用独立临时目录，关闭后清理。
  「截图问 AI」仍是独立功能，只有用户明确发送后才交给配置的模型。
- `Source code` 附件是源码，不是可直接运行的自包含程序。
