## 当前功能与边界

- WPF / .NET 8，Provider 中立；模型调用只经 `IAiProvider` 和工厂。
- V0.4：Excel 导入、本地中文课表 OCR、湖南工程学院用户登录后读取、冬夏节次、
  本周课表与下一节课、单次调课/补课、冲突检查、编辑预览与跨重启导入撤销。
- 同校登录后的 HTTP 降级请求仍被取消，只对受限重定向限次返回固定 HTTPS 入口。
  用户已验证不用手动重试即可进入，预览为 0 更新、13 重复、1 无效备注。
- 多教师比较忽略顺序和明确分隔符，不改变显示字符串，不隐藏真正增减教师。
- 本地 OCR 不需 Key，不调用模型服务；图片有截断时必须手动核对，不猜测缺失字段。
- 用户不希望反复执行整套旧功能验收。已测项目见记录，不要重新从头问一遍。
- 用户明确接受暂不补测系统 DPI 完整矩阵、无 WebView2 下载环境、异常退出清理、
  部分睡眠/课程提醒时间边界；保留披露，后续按反馈修复，不能写成已验证通过。
- 新版功能（例如语音/角色专属语言）尚未确定，不要擅自开始 V0.5 或更换角色素材。

## 常用验证

```powershell
.\scripts\build.ps1
.\scripts\test.ps1
. .\scripts\environment.ps1
dotnet build .\DragonDeskPet.sln -c Release --no-restore -warnaserror
```

`environment.ps1` 固定 D 盘项目内的 SDK/NuGet/TEMP 缓存；本机 SDK 为 .NET 9 预览版，
目标仍是 .NET 8，稳定 .NET 8 由远程 CI 验证。模型脚本会按固定 SHA 校验下载。

本机没有可用的 `gh` 命令。之前推送使用 Git 已有凭据；发布 API 可经同一标准凭据链，
凭据只存在进程内存，不写入文件或输出。若权限不足，停下让用户登录，不索取明文 Token。
提升权限后 Git 可能提示仓库所有者不同；仅对已核实的本项目使用命令级
`-c safe.directory="D:/Chat GPT/桌宠"`，不要设置全局 `safe.directory=*`。
