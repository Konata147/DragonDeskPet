## 常用验证

```powershell
.\scripts\build.ps1
.\scripts\test.ps1
. .\scripts\environment.ps1
dotnet build .\DragonDeskPet.sln -c Release --no-restore -warnaserror
```

`environment.ps1` 固定 D 盘项目内的 SDK/NuGet/TEMP 缓存；本机 SDK 为 .NET 9 预览版，
目标仍是 .NET 8，稳定 .NET 8 由远程 CI 验证。模型脚本会按固定 SHA 校验下载。

本机没有可用的 `gh` 命令。之前推送使用 Git 已有凭据；发布 API 可经同一标准凭据链，
凭据只存在进程内存，不写入文件或输出。若权限不足，停下让用户登录，不索取明文 Token。
提升权限后 Git 可能提示仓库所有者不同；仅对已核实的本项目使用命令级
`-c safe.directory="D:/Chat GPT/桌宠"`，不要设置全局 `safe.directory=*`。
