# 动作素材制作提示

## interactions.11 点心与舞蹈

使用内置 imagegen，以原角色图和已有完整互动帧为参考。共同提示：同一 Q 版龙娘，白紫长发、双角、紫眼、白紫裙、两只完整龙翼和龙尾；透明背景；2×2 四个完整角色姿势，四周留安全边距、比例与脚底基准一致；只改变指定表情、手脚或尾尖，不让身体横向钟摆旋转；不要文字、场景或额外人物。按动作分别提示：

| 源素材 | 四个关键姿势 |
|---|---|
| `FeedCookie` | 看到饼干、伸手接、双手举到嘴边、闭眼咀嚼 |
| `FeedStrawberry` | 好奇、双手迎接草莓、送到嘴边、开心眯眼 |
| `FeedCake` | 惊喜、接蛋糕、小口品尝、满足微笑 |
| `FeedCandy` | 期待、捧糖果、放入口中、甜蜜眨眼 |
| `FeedCottonCandy` | 捧棉花糖、靠近脸颊、轻尝、闭眼微笑 |
| `DanceStepA/B` | 起势、交替小踏步、手臂摆动、举手亮相和回站 |
| `DanceGuofengA/B` | 缓慢抬手、转腕、轻转步、垂眸、合手收势；只借鉴国风感觉 |
| `DanceWingTailA/B` | 双手带节奏、尾尖配合、转步、回站；另用完整单帧 `DanceWingTailOpen` 表现一次适度张翅 |

第一版草莓 3×2 源图碰到切分线，已弃用；全部最终源图位于 `assets/character/animations/sources/v11/`。`scripts/import-interaction-variants.py` 拒绝碰切分线的格子、去掉离散杂点，按头部和脚底锚点导出完整 512×512 透明帧，并登记五种投喂与三支 8 秒舞蹈。张翅动作使用独立单帧，源图不进入运行包。使用这些素材时继续目视检查头发、翼根、尾巴和衣摆在相邻姿势间的连续性；不能仅凭几何检查宣称连续动作完全流畅。

内置 imagegen 以 `references/character-original.jpg`、`references/chibi-animation-reference.jpg`、既有运行时状态图为视觉参考，先生成 `assets/character/animations/sources/pose-overview.png`，再分别生成 `sources/` 下 14 张透明 3×2 姿势图。每张图的六格均要求同一角色、同一比例、同一脚底锚点；保留白紫长发、双角、紫眼、龙翼、龙尾与白紫裙装。非跳跃动作仅改变指定部位，不平移或旋转整身；无背景、文字、边框或独立道具。运行时文件由 `scripts/import-animation-sheets.ps1` 切帧生成，原状态图保持不变。

| 源图 | 六格主要动作提示 |
|---|---|
| Greet | 站稳微笑，单手抬起并挥动两次，放下 |
| Pet | 闭眼，头轻轻低下迎合摸头，再抬起 |
| Feed | 双手接点心，送到嘴边，轻轻咀嚼 |
| Cuddle | 张开双臂，向前收拢，脸颊略靠近，停留 |
| Hop | 屈膝，垂直跳起，到顶点，落地站稳 |
| Dance | 左右小踏步，双臂交替摆动，身体不钟摆旋转 |
| Stretch | 双手举高，原位伸展，放下 |
| LookAround | 先移动眼神，再小幅转头，肩膀以下稳定 |
| Land | 膝部缓冲，手臂回到自然位置，只做一次 |
| Wake | 睁眼，揉眼，掩嘴打哈欠，回到站姿 |
| Celebrate | 双手举起，翅膀张合一次，原地庆祝 |
| Blink | 站姿不变，只做一次眨眼 |
| Tail | 站姿不变，只轻摆尾尖 |
| Sleep | 闭眼安睡，轻微局部呼吸 |

源图属于美术制作文件，不进入体验包；运行时只包含切帧 PNG 与 `clips.json`。摸头、蹦跳、庆祝源图已用内置 imagegen 返修，再通过切帧脚本去掉跨格孤立碎片。后续返修应先检查手部结构、脚底稳定、透明边缘与逐帧线条连续性，再重新切帧。

## interactions.3 修复素材

上一批 3×2 源图的六格太挤，招呼、摸头、贴贴等动作的翼尖碰到切分线。新一批源图保留在 `assets/character/animations/sources/v3/`，改为 2×3 布局，每格 512×512；庆祝张翅使用另行生成的完整单帧 `Celebrate-open.png`。这些文件仍是美术源，不参与运行时打包。

`interactions.3` 曾用宽区域蒙版把动作姿势叠到站姿上，造成双眼、双手甚至双头；`.4` 虽收窄合成区域，仍留下不属于动作角色的待机翅膀、头发与尾巴。`.5` 的 `scripts/import-animation-frames-v3.py` 不再合成任何待机身体部位：每帧只保留一幅完整动作角色，统一缩放、脚底锚点，并去掉跨格碎片；碰到切分线的格子不使用。首尾帧回到同一完整站姿，蹦跳只作纵向位移，庆祝使用一次完整张翅。新增悬停 `Hover` 四帧，以完整角色的眼神和头部变化表达“嗯？”。脚本依赖 Pillow 与 NumPy；本机可用 Codex 捆绑 Python 运行。运行时帧在 `assets/character/animations/<Id>/`，重新生成会覆盖工作树素材，但不覆盖旧状态图或既有体验包。

`.6` 对投喂和伸展只选同列源姿势，避免两列不一致的翼展轮廓交替造成摇晃；蜷卧睡姿改从原 `assets/character/sleeping.png` 完整导出。蹦跳的明显离地由 WPF 纵向位移动画负责，帧素材仍保持整张角色图。小 AI 在普通动作中由原 `default.png` 的云形象单独显示，睡姿则使用原图自带的闭眼云形象。新素材制作仍应保证关键姿势间翼根、头发与尾巴连续，现有几格姿势不能替代真正的高帧率逐帧绘制。
