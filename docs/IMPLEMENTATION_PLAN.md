# V0.1 implementation status

1. **Foundation — complete**: WPF/.NET 8 solution, repository rules, reference assets, D-drive build configuration, and formal application icon.
2. **Local services — complete**: portable settings, protected secrets, startup registration, seven-state asset lookup with per-state fallback, and redacted crash logs.
3. **Pet core — complete**: seven-state machine, inactivity transition, drag/hover/click/wheel interactions, safe drag completion, scale persistence, and position persistence.
4. **Desktop UI — complete**: transparent pet surface, seven production sprites, first-run mini guide, quick actions, context menu, compact chat bubble, and settings window.
5. **AI boundary — complete for V0.1**: provider contract, provider catalog, OpenAI-compatible transport, offline behavior, and friendly unavailable-provider responses.
6. **Windows integration — complete**: tray lifecycle, show/hide/settings/exit, single-instance wake-up pipe, window/EXE/tray icons, and explicit shutdown.
7. **Verification — complete**: zero-warning Debug build, automated smoke tests, Release publish, real second-process validation, and manual interaction checklist.

V0.2 screenshot, clipboard, file-ingestion, reminder, voice, and system-control features remain intentionally deferred.
