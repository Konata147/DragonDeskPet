# DragonDeskPet V0.3.0

V0.3.0 为龙娘桌宠加入完全本地的校园效率助手。原有聊天、截图、剪贴板和图片拖入功能继续保留；效率功能不需要 API Key。

## 新功能

- 角色旁的三页迷你气泡：今日课程与待办、提醒、专注。
- 单次与每日提醒；到点卡片支持完成和稍后 5/10/30 分钟，关闭程序或电脑睡眠期间错过的提醒会在恢复后补发。支持关闭提示音。
- 本地解析明确的提醒语句，保存前展示时间与内容供确认；不确定的语句不会猜测或发送给模型。
- 可调整时长与长休间隔的番茄钟；每阶段结束后暂停，须手动开始下一阶段。状态跨重启保存。
- 今日清单支持编辑、完成、恢复和删除；未完成事项次日结转，已完成事项保留七天。
- 大学课程表支持教学周、单双周、单日停课、课程提前提醒，以及带预览的 UTF-8 CSV 和 ICS 导入。导入可合并或明确替换；无有效课程时不会清空现有课表。
- 全屏程序运行时静默排队提醒；手动隐藏桌宠时只发送一次托盘提示，恢复后仍可处理。

## 使用与隐私

- 下载 `DragonDeskPet-v0.3.0-win-x64.zip`，完整解压后运行 `DragonDeskPet.exe`。此包自带 .NET 运行环境，适用于 Windows 10/11 x64。
- 提醒、清单、番茄钟和课程保存在程序旁 `data/productivity.json`，不会发送给 AI；导入预览确认前不会写入课表。
- 已有便携版用户可将旧版的 `data` 文件夹复制到新版程序旁，以保留设置和运行数据。复制前先退出旧版程序。
- 程序尚无数字签名或安装器；`Source code` 是 GitHub 自动提供的源码包，不是可直接运行的桌宠。
